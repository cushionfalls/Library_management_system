# Security Policy

## Supported Versions

Only the latest release/development version is supported for security updates:

| Version | Supported |
| --- | --- |
| 1.0.x / main |  Yes |
| < 1.0.0 |  No |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover any security vulnerabilities, please report them responsibly:

1.  Do not disclose security issues publicly (e.g., in GitHub Issues).
2.  Send an email to the repository owner or open a confidential issue if supported.
3.  Provide detailed steps, proof of concept (PoC), and environment details to help us reproduce the issue.

We will review your report and respond as quickly as possible with a remediation timeline.
